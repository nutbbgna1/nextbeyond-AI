# ตัวสร้างใบงานด้วย AI (PHP + Gemini)

กรอกหัวข้อ → Gemini วางแผนและสร้างใบงานทีละใบ → ตรวจคุณภาพอัตโนมัติ → สร้างภาพลายเส้น → พิมพ์/บันทึกเป็น PDF (ใบงาน + เฉลย)
ไม่ต้องติดตั้ง Node ไม่ต้องมีฐานข้อมูล ใช้ได้กับ XAMPP / MAMP / โฮสต์ PHP ทั่วไป

## ติดตั้งบน XAMPP (macOS)

1. แตกไฟล์ zip จะได้โฟลเดอร์ `worksheet-php` นำไปวางใน `htdocs`
   เช่น `/Applications/XAMPP/xamppfiles/htdocs/worksheet-php`
2. เปิด XAMPP แล้วกด Start ที่ **Apache** (ต้องใช้ PHP 8.0 ขึ้นไป และเปิด cURL ซึ่ง XAMPP เปิดไว้ให้แล้ว)
3. เปิดไฟล์ `config.php` ใส่ API key ตรงบรรทัด `'api_key' => '...'`
   (สร้างคีย์ที่ https://aistudio.google.com/apikey)
4. ให้โฟลเดอร์ `data` เขียนไฟล์ได้ (ใช้เก็บคลังภาพและโควตา) เปิด Terminal แล้วรัน:
   ```bash
   chmod -R 777 /Applications/XAMPP/xamppfiles/htdocs/worksheet-php/data
   ```
5. เปิด http://localhost/worksheet-php/check_models.php ต้องเห็น ✅ ครบ 3 บรรทัด
   ถ้ามี ❌ หน้านั้นจะแสดงรายชื่อโมเดลที่คีย์ของคุณใช้ได้ ให้แก้ชื่อใน `config.php` ส่วน `models`
6. เปิด http://localhost/worksheet-php/ แล้วลองสร้างใบงาน 2 ใบ ข้อละ 3-4 ข้อก่อน จะเห็นผลเร็วและเสียค่า API น้อย

## โมเดลที่เลือก (แก้ได้ใน config.php)

| หน้าที่ | ค่าเริ่มต้น | เหตุผล |
|---|---|---|
| วางแผน + สร้างเนื้อหา | `gemini-3.8-flash` | Flash รุ่นล่าสุด เร็ว ราคาถูก เหมาะกับงานที่วนทีละใบ |
| ตรวจความถูกต้อง | `gemini-3.1-pro-preview` | Pro เก่งเหตุผลกว่า เรียกน้อยครั้งจึงไม่แพง |
| สร้างภาพ | `gemini-3.1-flash-image` | Nano Banana 2 ภาพลายเส้นไม่ต้องใช้รุ่นแพง |

## การทำงาน

```
ฟอร์ม → api/plan.php   วางแผนว่าแต่ละใบใช้รูปแบบอะไร
      → api/sheet.php  ทีละใบ แยกเป็นคำขอสั้นๆ:
                         step=generate  สร้าง + ตรวจด้วยโค้ด (คำซ้ำ เฉลยอยู่ในตัวเลือกไหม ลำดับครบไหม)
                         step=review    ให้ Pro ตรวจความถูกต้อง
                       ไม่ผ่าน → สร้างใหม่พร้อมแจ้งปัญหา (สูงสุด 3 รอบ) หน้าเว็บเป็นตัววนซ้ำ
      → api/image.php  คิวสร้างภาพครั้งละ 3 ภาพ ภาพที่เคยสร้างแล้วใช้ซ้ำจากคลัง data/images
      → หน้าตัวอย่าง A4 → พิมพ์ / บันทึกเป็น PDF
```

วิธีกันปัญหา token เกิน: แยกคำขอทีละใบ, ใช้ `thinking_level` ต่ำ (token ที่ใช้คิดถูกนับรวมใน output),
ตรวจ `MAX_TOKENS` แล้วสร้างใหม่แทนการต่อ JSON ที่ขาด, ได้ 429 จะ retry แบบหน่วงเวลาเพิ่มเป็นเท่าตัว

บันทึกเป็น PDF: กด "พิมพ์ / บันทึกเป็น PDF" แล้วเลือกปลายทาง "บันทึกเป็น PDF" ขนาด A4 ขอบ "ไม่มี" และติ๊ก "กราฟิกพื้นหลัง"

## นำขึ้นอินเทอร์เน็ต (ต้องทำก่อน!)

- **ตั้งรหัสผ่าน** ในไฟล์ `config.php` ที่ `'app_password'` ไม่งั้นใครเจอลิงก์ก็ใช้โควตา API ของคุณได้
- ใช้ HTTPS
- ตั้ง `max_execution_time` ของ PHP อย่างน้อย 120 วินาที (แต่ละคำขอเรียกโมเดลแค่ครั้งเดียว ปกติไม่เกินครึ่งนาที)
- ปรับ `daily_limit_per_ip` เพื่อคุมค่าใช้จ่ายต่อวัน
- โฮสต์ Apache: ไฟล์ `.htaccess` ในโฟลเดอร์ `data` และ `src` กันการเปิดตรงอยู่แล้ว ถ้าใช้ Nginx ต้องตั้ง deny สองโฟลเดอร์นี้เอง

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ยังไม่ได้ใส่ API key | แก้ `api_key` ใน `config.php` |
| ไม่พบโมเดล (404) | เปิด `check_models.php` แล้วแก้ชื่อใน `models` ให้ตรงกับรายการที่แสดง |
| 429 เรียกถี่/เกินโควตา | รอสักครู่ ระบบ retry ให้เองระดับหนึ่งแล้ว ถ้าเกิดบ่อยให้ลดจำนวนข้อ/ใบ |
| บันทึกภาพไม่ได้ | โฟลเดอร์ `data` ไม่มีสิทธิ์เขียน ทำขั้นตอนที่ 4 |
| เซิร์ฟเวอร์ตอบกลับผิดรูปแบบ | PHP error: ดูที่ `/Applications/XAMPP/xamppfiles/logs/php_error_log` |
| SSL certificate problem | ตั้ง `curl.cainfo` ใน `php.ini` ให้ชี้ไฟล์ CA bundle (cacert.pem) |

## โครงสร้างไฟล์

- `config.php` จุดใส่ API key / โมเดล / รหัสผ่าน / โควตา
- `index.php` หน้าเว็บ + ล็อกอิน, `assets/js/pages/app.js` ตรรกะหน้าเว็บและเทมเพลต A4, `assets/css/style.css`
- `api/` plan, sheet, image, img (ส่งไฟล์ภาพจากคลัง)
- `src/` โค้ดฝั่งเซิร์ฟเวอร์ แยกเป็น core / ai / worksheet / planning / reference (ดูแผนที่ใน `docs/STRUCTURE.md`)
- `data/` คลังภาพและโควตา (บล็อกไม่ให้เปิดตรง)

## ข้อจำกัดของต้นแบบ

- ยังไม่มีบัญชีผู้ใช้หลายคน (มีรหัสผ่านเดียว) และยังไม่บันทึกประวัติใบงาน
- แก้ข้อความในหน้าตัวอย่างโดยตรงไม่ได้ มีแค่ปุ่ม "สร้างใบนี้ใหม่" พร้อมคำแนะนำ
- ถ้าใบงานมี 8 ข้อและทุกข้อมีภาพ เนื้อหาอาจล้นหน้า A4 ควรทดสอบกับหัวข้อจริงแล้วปรับ `assets/css/style.css`
- โควตานับตาม IP ถ้าหลายคนใช้ผ่าน IP เดียวกันจะแชร์โควตากัน


## ใช้ OpenAI / OpenRouter ได้ด้วย

หน้าเว็บมีช่องเลือก "AI สร้างเนื้อหา + ตรวจทาน" และ "AI สร้างภาพ" แยกกัน เลือกได้ทั้ง Gemini, OpenAI และ OpenRouter ทุกครั้งที่สร้าง
ใส่คีย์ใน `config.php`: `api_key` (Gemini), `openai_api_key`, `openrouter_api_key` ตัวเลือกที่ยังไม่มีคีย์จะเลือกไม่ได้

**OpenRouter**: เมื่อเลือกจะมีกล่อง "โมเดลจาก OpenRouter" กด "นำเข้ารายชื่อโมเดล" เพื่อดึงรายการล่าสุด (แคช 1 ชั่วโมง) แล้วพิมพ์ค้นหา/เลือกโมเดลเนื้อหา โมเดลตรวจทาน (ว่าง = ใช้ตัวเดียวกับเนื้อหา) และโมเดลภาพ
ติ๊ก "เฉพาะโมเดลฟรี" เพื่อกรองรุ่น `:free` ได้ โมเดลที่มี JSON✓ รองรับ schema ตรงๆ รุ่นที่ไม่มีระบบจะใช้โหมดสำรอง (ฝัง schema ในพรอมต์) ซึ่งอาจผิดรูปแบบบ่อยกว่า


## รวมใบงานเป็นเล่ม (book.php)
เปิดที่ `http://localhost/ai/book.php` (มีลิงก์ที่หน้าแรก)
1. เลือกใบงานจากชุดที่บันทึกไว้ (ทั้งชุด หรือติ๊กเฉพาะบางใบ) แล้วจัดลำดับ ▲▼ / ลบ / ตั้งชื่อหมวด
2. กด “ให้ AI ทำปก คำนำ สารบัญ” — AI เรียก 1 ครั้งเพื่อคิดชื่อเล่ม ชื่อรอง คำขวัญ คำนำ ภาพปก และจัดหมวดใบงาน (ระบบตรวจ uid ให้ครบไม่ซ้ำ) แล้วสร้างภาพปกลายเส้นต่อ แก้ข้อความได้ทุกช่อง
3. หน้าในเล่ม: ปก → คำนำ → สารบัญ (เลขหน้าคำนวณให้เอง รองรับสารบัญหลายหน้า) → ใบงาน → เฉลย (ปิดได้)
4. เล่มบันทึกอัตโนมัติใน `data/books/` (ฝังเนื้อหาใบงานไว้ในเล่ม จึงไม่กระทบชุดต้นทาง) เปิดกลับมาแก้ได้จาก “เล่มที่บันทึกไว้” แล้วกด “พิมพ์ / บันทึกเป็น PDF”
ไฟล์ที่เกี่ยวข้อง: `book.php`, `assets/js/pages/book.js`, `assets/css/book.css`, `assets/js/shared/render.js` (แม่แบบใบงานที่ใช้ร่วมกับหน้าแรก), `api/book_ai.php`, `api/books.php`


## ใบงานระดับมัธยม (สไตล์ทางการ) และใบความรู้
- **รูปแบบเอกสาร**: “อัตโนมัติตามชั้น” = ป.1–6 ใช้แบบน่ารักเดิม, ม.1–6 ใช้แบบทางการ (ฟอนต์ Sarabun หัวกระดาษรายวิชา/รหัสวิชา/ชื่อครู) เปลี่ยนเองได้
- **รูปแบบโจทย์ใหม่**: เติมคำตอบ/ตอบสั้น, คำนวณแสดงวิธีทำ (มีบรรทัดเขียน เฉลยแสดงวิธีทำ), ปรนัยเลือกข้อความถูก (1, 2, 3) — ระบบสร้างตัวเลือก ก–ง จากชุดข้อความเองจึงไม่ผิด, ชุดคำถามจากข้อมูล/กราฟ, แบบทดสอบ 2 ตอน (หัวกระดาษโรงเรียน คะแนนเต็ม เวลาสอบ)
- **ระดับความยาก**: พื้นฐาน / ปานกลาง / แนวข้อสอบ (AI ถูกห้ามอ้างว่าเป็นข้อสอบจริง เช่น O-NET)
- **สูตร**: AI เขียนเป็น LaTeX แสดงผลด้วย KaTeX ที่เก็บไว้ในเครื่อง (`assets/katex/`, MIT license) พิมพ์ได้แม้ไม่มีอินเทอร์เน็ต
- **รูปประกอบ**: “ระบบวาดเอง” = กราฟ แผนภาพวัตถุ/แรง และตาราง วาดจากข้อมูลที่ AI ส่งมา (ค่าบนกราฟตรงกับเฉลย) ส่วนภาพทั่วไปให้ AI วาดแบบลายเส้นหนังสือเรียน, หรือเลือก “ให้ AI สร้างภาพทั้งหมด” / “ไม่ใช้รูป”
- **ตรวจคำตอบตัวเลข**: โจทย์คำนวณมี `checkExpr` ระบบคำนวณซ้ำฝั่งเซิร์ฟเวอร์ ถ้าไม่ตรงกับเฉลย (เกิน 2%) จะสั่ง AI สร้างใหม่อัตโนมัติ
- **แบ่งหน้าอัตโนมัติ**: ใบที่ยาวเกิน A4 ถูกตัดขึ้นหน้าใหม่ทีละข้อ (ไม่ตัดกลางข้อ) เลขหน้ารันต่อกันทั้งชุด
- **ใบความรู้ 1 ฉบับต่อ 1 ใบงาน**: ติ๊ก “สร้างใบความรู้” ตอนสร้าง หรือกด “＋ ใบความรู้” ที่แถบเหนือใบงานภายหลัง (↻ สร้างใหม่ / ลบได้) ประกอบด้วยบทนำ หัวข้อย่อย กล่องสูตร ตารางตัวแปร รูป ตัวอย่างพร้อมวิธีคิด ข้อควรระวัง และตารางสรุป แสดงก่อนใบงาน (ไม่แสดงในโหมดเฉลย) บันทึกไปกับชุด และหน้ารวมเล่มใส่ไว้ก่อนใบงานพร้อมขึ้นในสารบัญ

## แผนการจัดการเรียนรู้ (lplan.php) — เริ่มที่นี่
ลำดับการใช้งานที่แนะนำ: **แผนภาคเรียน → แผนการจัดการเรียนรู้ → ใบงาน/ใบความรู้ → รวมเล่ม**
- กรอกชั้น วิชา ภาคเรียน หน่วย เรื่อง เวลา (ชั่วโมง × นาทีต่อคาบ) เลือกรูปแบบกิจกรรม (ขั้นนำ-สอน-สรุป / 5E / GPAS 5 Steps / Active Learning) และตัวชี้วัด แล้วให้ AI ร่าง
- แผนมีครบ: ตัวชี้วัด สาระสำคัญ จุดประสงค์ K-P-A สาระการเรียนรู้ สมรรถนะสำคัญ 5 ประการ คุณลักษณะอันพึงประสงค์ 8 ประการ ตารางกิจกรรมครู/นักเรียนพร้อมเวลา (ระบบปรับให้รวมเท่าเวลาเรียนจริง) ภาระงาน สื่อ ตารางการวัดผล และบันทึกหลังสอน + ช่องลงชื่อ
- แก้ไขได้ทุกช่อง บันทึก พิมพ์/PDF (A4) หรือดาวน์โหลดเป็น Word (.doc ฟอนต์ TH Sarabun New 16pt)
- "สร้างใบงานตามแผน": เปิดหน้าสร้างใบงานพร้อมใบงานที่แผนกำหนด (ไม่ต้องให้ AI วางแผนซ้ำ) และส่งสาระสำคัญ/จุดประสงค์/สาระการเรียนรู้ของแผนให้ AI ทุกครั้งที่สร้างใบงานและใบความรู้ ชุดที่บันทึกจะจำว่ามาจากแผนไหน
- AI ไม่แต่งรหัสตัวชี้วัด (รหัสที่ไม่มีในระบบถูกตัดออก) ถ้ายังไม่ได้นำเข้าตัวชี้วัด แผนจะเว้นให้ครูเติม

## คลังเอกสารอ้างอิง (library.php)
อัปโหลด PDF/DOCX/TXT (หนังสือเรียน แผนการสอน หลักสูตรสถานศึกษา) แล้วติดป้ายชั้น/วิชา/ชนิดเอกสาร ระบบดึงข้อความในเบราว์เซอร์ (ไม่มี OCR จึงอ่านไฟล์สแกนเป็นรูปไม่ได้ และไม่เก็บไฟล์ต้นฉบับ เก็บเฉพาะข้อความ)
- **เอกสารอ้างอิง**: ตอนสร้างใบงาน ระบบค้นท่อนที่เกี่ยวข้องตามชั้น/วิชา/หัวข้อ ส่งให้ AI เป็น "ข้อมูลอ้างอิง" (ไม่ใช่คำสั่ง)
- **บทอ่าน (passage)**: เลือกท่อนข้อความยาวจากคลัง ระบบพิมพ์ลงใบงาน "ตรงตามต้นฉบับ" พร้อมที่มา ให้ AI สร้างเฉพาะคำถาม
- ถ้าอัปโหลดไฟล์ใหญ่ไม่ได้ ให้เพิ่ม `upload_max_filesize` / `post_max_size` ใน php.ini (XAMPP: /Applications/XAMPP/xamppfiles/etc/php.ini)

## คลังใบงาน (saved.php)
จัดหมวดอัตโนมัติตามชั้น/วิชา/ปีการศึกษา/ภาคเรียน ค้นหาเต็มข้อความ กรองตามชนิด ระดับความยาก ใบความรู้ ตัวชี้วัด จัดโฟลเดอร์เอง ตั้งสถานะ (ร่าง/ตรวจแล้ว/ใช้สอนแล้ว) ทำสำเนา เพิ่มลงเล่ม และถังขยะเก็บ 30 วัน

## หลักสูตรและตัวชี้วัด (curriculum.php)
รองรับหลักสูตรหลายฉบับ (เช่น แกนกลาง 2560 และฉบับอื่นในอนาคต) ตั้งฉบับที่ใช้เป็นค่าเริ่มต้นและกำหนดรายชั้นต่างจากค่าเริ่มต้นได้
- ระบบ **ไม่แถมข้อมูลตัวชี้วัดทางการ** ให้ดาวน์โหลด PDF ตัวชี้วัด/สาระการเรียนรู้แกนกลางจาก สพฐ./สสวท. แล้วนำเข้าในแท็บ "นำเข้า" (ถอดด้วยรูปแบบรหัส หรือให้ AI ช่วยถอด แล้วตรวจทานก่อนบันทึก) และจับคู่ตัวชี้วัดกับหน่วยการเรียนรู้
- หน้าสร้างใบงานเลือกตัวชี้วัดได้ ระบบพิมพ์รหัสตัวชี้วัดท้ายใบงาน/ในเฉลย และเล่มสรุปว่าครอบคลุมตัวชี้วัดกี่รายการ
- ข้อจำกัด: AI ไม่สามารถ "รับรองตามกฎกระทรวง" ได้ ใช้คำว่า "อ้างอิงหลักสูตรแกนกลางฯ" และครูควรตรวจทานทุกครั้ง

## ระดับความยาก 4 ระดับ
ง่าย / ปานกลาง / ยาก / ยากมาก (ระดับเดียวทั้งใบ) หรือแบบผสมตามสัดส่วน (ทบทวน, มาตรฐาน, เตรียมสอบ, แข่งขัน, กำหนดเอง) ระบบคำนวณจำนวนข้อต่อระดับ เรียงจากง่ายไปยาก และตรวจว่าตรงตามที่ขอ ข้อ "ยากมาก" เลือกให้เกินขอบเขตชั้นได้ (เทียบข้อสอบแข่งขัน แต่เป็นข้อที่ AI แต่งใหม่ ไม่ใช่ข้อสอบจริง)

## คลังข้อสอบ (bank.php)
เก็บโจทย์รายข้อจากชุดที่บันทึกไว้ (คลังใบงาน → เลือกชุด → "เก็บเข้าคลังข้อสอบ") กรองตามชั้น/วิชา/ชนิด/ระดับ/ตัวชี้วัด/ข้อความ แล้วเลือกข้อมาประกอบเป็นชุดใหม่ (แยกใบตามชนิดโจทย์) ข้อซ้ำไม่ถูกเก็บซ้ำ ข้อที่ใช้รูปประกอบ บทอ่าน หรือสื่อร่วม (data_set) จะข้าม เพราะแยกออกมาแล้วไม่ครบ

## แผนทั้งภาคเรียน (term.php)
ให้ AI ร่างแผนรายสัปดาห์ (หน่วย หัวข้อ ชนิดใบงาน ตัวชี้วัด สัปดาห์ทบทวน/สอบ) แก้ไขในตารางได้ บันทึกและพิมพ์ได้ ปุ่ม "สร้างใบงาน" ของแต่ละสัปดาห์เปิดหน้าสร้างใบงานพร้อมหัวข้อ ชนิด และตัวชี้วัดที่เลือกไว้ รายงานว่าครอบคลุมตัวชี้วัดกี่รายการ

## เทียบตัวชี้วัดต่างฉบับ (หลักสูตร → แท็บ 4)
เมื่อมีหลักสูตรฉบับใหม่ นำเข้าตัวชี้วัดวิชานั้นทั้งสองฉบับ ให้ AI เสนอการจับคู่ แล้วครูตรวจแก้และบันทึก (รหัสที่ไม่มีอยู่จริงถูกตัดออกอัตโนมัติ) เป็นร่างช่วยย้ายใบงาน ไม่ใช่ตารางเทียบทางการ

## ส่งออก/นำเข้า zip (คลังใบงาน)
เลือกชุด → "ส่งออก zip" ได้ไฟล์ .json ต่อชุด (ใช้สำรองหรือส่งต่อ ไม่รวมไฟล์ภาพ ภาพที่ขาดกดสร้างใหม่ได้) และ "นำเข้า zip/json" เพิ่มเป็นชุดใหม่ ไม่ทับของเดิม

## ข้อสอบ (exam.php)
สร้างข้อสอบกลางภาค/ปลายภาค/ท้ายหน่วย ได้ทั้งฉบับในหน้าเดียว
1. ตั้งโครงสร้าง: ปรนัย 4 ตัวเลือก, ถูก-ผิด, จับคู่, อัตนัย (จำนวนข้อ + คะแนนต่อข้อ) สัดส่วนความยาก 4 ระดับ และติ๊กตัวชี้วัดที่ออกสอบ
2. กด "ดูตารางวิเคราะห์" ดูตารางตัวชี้วัด × ระดับ (ไม่เรียก AI) และดูว่าคลังข้อสอบมีข้อที่ตรงกี่ข้อ
3. กด "สร้างข้อสอบ": ระบบหยิบจากคลังข้อสอบก่อน (ตรงชั้น วิชา ตัวชี้วัด ระดับ) แล้วให้ AI สร้างเฉพาะข้อที่ขาด พร้อมตรวจอัตโนมัติ (ตัวเลือกซ้ำ เฉลยซ้ำตำแหน่งเดียว ตรวจตัวเลขอัตนัยด้วยการคำนวณซ้ำ)
4. แท็บ "แก้ไขข้อสอบ" แก้ได้ทุกข้อ หรือกด "สร้างข้อใหม่" รายข้อ ปรับคะแนนต่อข้อได้
5. แท็บ ข้อสอบ / กระดาษคำตอบ / เฉลย พิมพ์ทีละแท็บ ได้ทุกชุด (ก ข ค ง): ชุด ก = ลำดับเดิม ชุดอื่นสลับข้อและตัวเลือก (ตัวเลือกที่อ้างถึงกันอย่าง "ทั้ง ก และ ข" จะไม่ถูกสลับ) เฉลยคำนวณตามชุดนั้นเอง
6. บันทึกแล้วเปิดแก้ภายหลังได้ และเลือกเก็บข้อที่ AI สร้าง/ครูแก้เข้าคลังข้อสอบ เพื่อให้ครั้งต่อไปดึงมาใช้ได้

ข้อสอบจาก AI ครูควรตรวจทานทุกข้อก่อนใช้จริง จับคู่นับเป็นระดับ "ง่าย" ในตารางวิเคราะห์ ข้อที่ต้องใช้รูปภาพยังไม่รองรับในหน้านี้

## ตั้งค่า AI (settings.php)
ใส่ API key (Gemini / OpenAI / OpenRouter) และเลือกผู้ให้บริการ + โมเดลได้จากหน้าเว็บ แยกตามเมนู: สร้างใบงาน (มีโมเดลตรวจทานแยก), ภาพประกอบ, แผนการสอน, แผนภาคเรียน, ข้อสอบ, รวมเล่ม, ตัวชี้วัด
- ลำดับความสำคัญ: ตั้งเฉพาะเมนู > ค่าเริ่มต้นในหน้าตั้งค่า > ตัวเลือกในหน้าสร้างใบงาน > config.php
- เมนูที่เลือกผู้ให้บริการเอง โมเดลต้องเป็นของผู้ให้บริการนั้น ถ้าเว้นผู้ให้บริการไว้ จะเปลี่ยนเฉพาะโมเดลของผู้ให้บริการเริ่มต้นได้
- ปุ่ม "นำเข้ารายชื่อโมเดล" ดึงรายชื่อจากบริการมาให้เลือก (พิมพ์ชื่อเองได้เสมอ) และปุ่ม "ทดสอบการเชื่อมต่อ" ยิงคำขอเล็กๆ 1 ครั้ง (นับโควตา 1)
- คีย์ที่ตั้งในหน้านี้เก็บที่ data/settings/ (เว็บเปิดอ่านไม่ได้) และใช้ก่อนคีย์ใน config.php หน้าจอไม่แสดงคีย์เต็มซ้ำ ล้างคีย์แล้วจะกลับไปใช้ config.php
