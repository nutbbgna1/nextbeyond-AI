# แผนพัฒนาระบบสร้างแผนภาพประกอบการสอน (Teaching Diagram Studio & Catalog)

ระบบสตูดิโอสร้างแผนภาพประกอบการสอนแบบครบวงจรสำหรับครูผู้สอน ครอบคลุมวิชาวิทยาศาสตร์ (ชีววิทยา เคมี ฟิสิกส์ ดาราศาสตร์) คณิตศาสตร์ และสังคมศึกษา พร้อมคลังแผนภาพหลักสูตร คอนโทรลเลอร์สลับโหมดข้อสอบ (เว้นว่างใส่หมายเลข) และโหมดเฉลย (คำบรรยายครบถ้วน) ส่งออกไฟล์เวกเตอร์ SVG และภาพ PNG คมชัดสูง และเชื่อมต่อเข้าสู่ระบบสร้างข้อสอบและใบงานได้ทันที

---

### การตัดสินใจและข้อสรุปจากผู้ใช้ (Confirmed Decisions)

> [!IMPORTANT]
> สรุปแนวทางที่ผู้ใช้เลือกในรอบที่ 1 เพื่อนำมาผสานเข้ากับระบบ:

- **รูปแบบการใช้งานหลัก (เลือก 1 และ 3)**:
  1. **สตูดิโอสร้างแผนภาพแยกเดี่ยว (Dedicated Diagram Studio)**: หน้าจอเฉพาะทางพร้อม Interactive Stage และ Control Deck สำหรับเลือกวิชา ปรับแต่งป้ายชี้ กำหนดขนาด และกดปุ่มส่งออกเข้าสู่ข้อสอบ/ใบงานได้ในคลิกเดียว
  2. **คลังแผนภาพสื่อการสอนสำเร็จรูป (Curriculum Diagram Catalog)**: หน้าค้นหา กรองแยกตามหมวดหมู่ (วิทยาศาสตร์, คณิตศาสตร์, สังคมศึกษา, ภาษาไทย, ภาษาอังกฤษ, วิทยาการคำนวณ) มีพรีวิวขนาดใหญ่ ดาวน์โหลด และนำไปใช้งานได้ทันที
- **โหมดการแสดงผล (สลับได้ 2 โหมด)**:
  1. **โหมดข้อสอบ (Exam / Blank Callout Mode)**: แสดงโครงสร้างภาพครบถ้วน แต่ป้ายชี้ระบุเป็นหมายเลข (1, 2, 3...) หรือเว้นกล่องข้อความว่าง เพื่อให้นักเรียนเขียนตอบหรือใช้เป็นโจทย์ข้อสอบ
  2. **โหมดเฉลยและการสอน (Teaching / Answer Key Mode)**: แสดงชื่อเรียกโครงสร้าง 2 ภาษา (ไทย-อังกฤษ) พร้อมคำอธิบายหน้าที่และหน้าที่การทำงานแบบละเอียด
- **รูปแบบไฟล์และการส่งออก (SVG & PNG)**:
  - ดาวน์โหลดไฟล์เวกเตอร์ SVG คมชัด 100% ไม่แตกเมื่อขยายสำหรับทำโปสเตอร์หรือสื่อฉายโปรเจกเตอร์
  - ส่งออกเป็นไฟล์รูปภาพ PNG ความละเอียดสูง (2x/3x Retina resolution) พร้อมใช้งานใน Word, PowerPoint, Google Slides
  - ปุ่มคัดลอกโค้ด SVG (Copy SVG Code) และปุ่ม "แทรกไปยังระบบสร้างข้อสอบ" (Insert into Exam Builder)

### 1. ภาพรวมและแนวคิดหลัก (Overview & Core Concept)

- **สิ่งที่ระบบทำได้ (What It Does)**:
  - **Interactive 2-Zone Sandbox**: ฝั่งซ้ายเป็น Stage แสดงผลภาพเวกเตอร์โครงสร้าง 3D/2D เกรดตำราเรียน ฝั่งขวาเป็น Control Deck ปรับแต่งหมวดหมู่, เรื่อง, โหมดแสดงผล (ข้อสอบ/เฉลย), ภาษา (ไทย/อังกฤษ/สองภาษา), และรายละเอียดป้ายชี้
  - **AI Diagram Prompt Generator**: หากต้องการแผนภาพเฉพาะเรื่องที่ไม่มีในคลัง ครูสามารถพิมพ์คำสั่ง (เช่น "วัฏจักรน้ำในธรรมชาติ", "พีทาโกรัสแสดงพื้นที่สี่เหลี่ยมบนด้านทั้งสาม", "แผนผังระบบสุริยะ") ระบบจะใช้ Gemini AI สร้างโครงสร้างแผนภาพ SVG เวกเตอร์ที่มีมาตรฐานวิชาการ สวยงาม และถูกต้องตามหลักการสอน
  - **Curriculum Library (33+ แผนภาพมาตรฐาน)**: ครอบคลุมฟิสิกส์ (วงจรไฟฟ้า, เลนส์, กฎนิวตัน), เคมี (ตารางธาตุ, โมเลกุล, เซลล์กัลวานิก), ชีววิทยา (เซลล์พืช 3D, เซลล์สัตว์ 3D, สังเคราะห์ด้วยแสง, หัวใจ), ดาราศาสตร์ (ข้างขึ้นข้างแรม, ระบบสุริยะ), คณิตศาสตร์ (ทฤษฎีบทพีทาโกรัส, ตรีโกณมิติ, ภาคตัดกรวย), สังคมศึกษา (โครงสร้างชั้นบรรยากาศ, แผนที่ภูมิศาสตร์, ไทม์ไลน์ประวัติศาสตร์)
  - **Exam & Worksheet Seamless Bridge**: เชื่อมต่อโดยตรงกับหน้า `exam.php` และ `bank.php` โดยส่งพารามิเตอร์ SVG และชุดข้อสอบอิงแผนภาพเข้าไปสร้างใบสอบได้ทันที

- **กลุ่มผู้ใช้งาน (Target Audience)**:
  - ครูผู้สอนระดับประถมและมัธยมศึกษา ที่ต้องการภาพประกอบบทเรียนคุณภาพสูง สวยงาม ถูกต้องตามหลักสูตรแกนกลาง และสร้างข้อสอบวัดผลเชิงประยุกต์ได้รวดเร็ว

- **ชุดสีและอัตราส่วน (60-30-10 Color Budget)**:
  - **60% พื้นหลังผืนผ้าใบ (Canvas)**: Slate-50 (`#F8FAFC`) สะอาด สบายตา ให้ความรู้สึกเหมือนกระดาษคุณภาพสูงในห้องปฏิบัติการ
  - **30% แผงควบคุมและเส้นแบ่งโครงสร้าง**: ขอบเส้นกริตบาง (`#E2E8F0`), การ์ดสีขาวบริสุทธิ์ (`#FFFFFF`), ตัวอักษรสี Slate-900 และ Slate-600
  - **10% จุดเน้นแอ็กชัน (Action Accents)**:
    - Primary CTA: สี Indigo-600 (`#4F46E5`) สำหรับการสร้างและการส่งออก
    - Exam Mode Active: สี Amber-600 (`#D97706`) แจ้งเตือนสถานะแบบฝึกหัด
    - Answer/Teaching Mode Active: สี Emerald-600 (`#059669`) แจ้งเตือนสถานะเฉลย
- **การพิมพ์และลำดับชั้น (Typography)**:
  - หัวเรื่อง Display: `Plus Jakarta Sans` และฟอนต์ไทยสุภาพชัดเจน รองรับสัญลักษณ์วิทยาศาสตร์และคณิตศาสตร์
  - ลำดับหมายเลขและป้ายชี้: ใช้ `tabular-nums` และฟอนต์โมโนสเปซคมชัดสำหรับตัวเลข 1–10 บนเส้นชี้นำสายตา
- **ความใส่ใจในรายละเอียด (Anti-Slop Discipline)**:
  - ไม่ใช้ Tag แคปซูลซ้อนกัน (Zero-Pill Metadata)
  - ไม่ใช้คำศัพท์หรูหราเกินจริง ใช้ภาษาที่เป็นมิตรและเป็นทางการสำหรับครู
  - ตัวสลับโหมดเป็น Segmented Control ชัดเจน พร้อม Tooltip อธิบายประโยชน์การนำไปใช้

### 4. ขั้นตอนการดำเนินงานและการทดสอบ (Implementation Phases)

1. **Phase 1: พัฒนาระบบแกนกลางสำหรับรองรับ Exam Mode / Teach Mode**
   - อัปเดต `src/server/svg-diagrams.ts` ให้ฟังก์ชันวาดแผนภาพรับพารามิเตอร์ `options: { mode: 'exam' | 'teach', lang?: 'th' | 'en' | 'both' }`
   - ในโหมด `exam`: หมายเลขชี้ตำแหน่งจะเว้นว่างหรือแสดงเฉพาะเลขวงกลม (1, 2, 3...) เพื่อใช้เป็นข้อสอบ
   - ในโหมด `teach`: แสดงชื่อโครงสร้าง คำอธิบายหน้าที่ และคู่มือครู

2. **Phase 2: สร้างหน้าสตูดิโอแผนภาพ `diagrams.php` และเพิ่มเมนูใน `nav.php`**
   - สร้างไฟล์ `/diagrams.php` เป็นสตูดิโอเต็มรูปแบบ ออกแบบตาม Education Simulation Guidelines:
     - แถบค้นหาและตัวกรองหมวดหมู่วิชา (วิทยาศาสตร์, คณิตศาสตร์, สังคมศึกษา, อื่นๆ)
     - Interactive Preview Stage ปรับย่อ-ขยาย (Zoom / Pan) และสลับโหมดได้แบบเรียลไทม์
     - ตัวแปลงและดาวน์โหลด SVG / PNG (สร้าง Blob URL ความละเอียดสูง)
     - ตัวคัดลอกโค้ด SVG เข้า Clipboard
     - ปุ่ม "สร้างข้อสอบจากแผนภาพนี้" นำพารามิเตอร์ส่งไปยัง `exam.php` พร้อมตั้งชื่อโจทย์อัตโนมัติ
   - ปรับปรุง `/src/core/nav.php` ให้มีเมนู "สตูดิโอแผนภาพ" อย่างเป็นทางการ

3. **Phase 3: สร้าง API Endpoints ใน `src/server/api.ts` และ `src/server/ai.ts`**
   - เพิ่ม Route `/api/diagrams/catalog` สำหรับดึงรายการแผนภาพทั้งหมดพร้อมคำอธิบาย ตัวชี้วัด และระดับชั้น
   - เพิ่ม Route `/api/diagrams/render` รองรับการเรนเดอร์ทั้งแบบ Raw SVG และ JSON Metadata
   - ปรับปรุง AI Diagram Generator ให้รองรับการสั่งวาดภาพเชิงโครงสร้างใหม่ผ่าน Gemini 2.5 Flash พร้อม Fallback เวกเตอร์ที่สวยงาม

4. **Phase 4: เชื่อมโยงเข้าสู่ระบบสร้างข้อสอบและใบงาน (`exam.php` & `bank.php`)**
   - เพิ่มปุ่ม "เลือกแผนภาพประกอบจากสตูดิโอ" ในหน้าสร้างข้อสอบ `exam.php`
   - ครูสามารถคลิกเลือกแผนภาพจากคลังแล้วนำมาเป็นภาพโจทย์ของข้อสอบข้อใดข้อหนึ่งได้ทันที

5. **Phase 5: ทดสอบความถูกต้อง (Verification & Build Check)**
   - รันการทดสอบ Unit Tests `npm test` เพื่อตรวจสอบความสมบูรณ์ของโค้ด
   - รัน `compile_applet` และ `lint_applet` ร่วมกันเพื่อยืนยันว่าไม่มีข้อผิดพลาดด้านไวยากรณ์หรือการ Import
   - ตรวจสอบการแสดงผลทั้งในโหมดข้อสอบและโหมดเฉลย การส่งออกไฟล์ SVG/PNG และความถูกต้องตามหลักสูตร

### แผนการส่งมอบงาน (Readiness for Review)
แผนงานนี้ครอบคลุมความต้องการของครูผู้สอนอย่างสมบูรณ์ ทั้งระบบสตูดิโอ คลังแผนภาพ การสลับโหมดข้อสอบ/เฉลย และการส่งออกเวกเตอร์ความคมชัดสูง พร้อมให้ท่านกด "Proceed" เพื่อเริ่มการพัฒนาได้ทันที
